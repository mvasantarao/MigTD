## Changes made

1. [Shared SNP validator](../../../src/pal/src/snp/qvl/validate.rs):
   retain the expected 48-byte digest check and reject any nonzero byte in
   REPORT_DATA positions 48 through 63 with `PalError::VerificationFailed`.
   Update directly related validation documentation.
2. Add positive coverage for a nonzero digest followed by zero padding and
   negative coverage for each of the 16 padding positions independently.
3. [Signed-fixture regression](../../../src/snp_emu/src/report_emu.rs):
   verify that the existing captured report has zero padding and still passes
   the selected `SnpQvl` backend, including signature/collateral verification.

Both TAV and Azure-backed `SnpEvidenceVerifier` implementations call the same
corrected `validate()` function. The existing 48-byte expected-digest API is
unchanged: the validator checks the remaining 16 bytes against canonical zeros.

No change was made to report generation, quote-named compatibility helpers,
SPDM wire records, trust anchors, or TDX behavior. This correction adds no new
secret and does not change secret ownership or lifetime.

### Implemented contract surface

- [REPORT_DATA context](../../../src/pal/src/snp/report_data_context.rs):
  preserve the exact 220-byte encoding, offsets, domain and existing numeric
  allocations; adopt the frozen tenant-binding, purpose-binding and combined
  MA/policy-identity field names. Register purposes 1-5, roles 0-3, and
  algorithms `0x0000`, `0x0003`, `0x0004`. Validate every legal combination on
  encode and decode, including zero tenant binding/local version 1 for local
  operations and zero TH1 for recovery.
- [Purpose bindings](../../../src/pal/src/snp/purpose_binding.rs):
  canonical tenant/result sets; successful persisted-installation and
  post-install preimages; planned/recovery prepare and firmware-confirmation
  records; exact-stage, identity, result-completeness and trusted-current-record
  checks. Planned/recovery preimages are exactly 281/282 bytes respectively.
  Recovery serializes no outgoing evidence, signature, SPDM transcript, secret,
  or opaque routing handle; trailing additions fail.
- Tenant identities have a private representation and can enter a public
  canonical tenant set only through host-requested report verification. The
  existing verifier authenticates the report before REPORT_ID is extracted;
  raw host routing identifiers cannot construct these values. This narrow
  identity token is not the future common authenticated-claims implementation.
- Use the already-patched ring SHA-384 implementation directly as an optional
  SNP-only PAL dependency. This avoids pulling the crypto crate's TLS stack
  into PAL. Default PAL/TDX dependencies remain unchanged. No new cryptographic
  primitive, handoff-secret derivation, or HKDF construction was invented.
- [Shared SNP validation](../../../src/pal/src/snp/qvl/validate.rs) and both
  [existing verifier backends](../../../src/pal/src/snp/qvl/verify.rs) distinguish
  Version 6 guest-requested MA reports from host-requested tenant reports.
  Guest VMPL must match the selected value 0-3. Host VMPL must be `0xffffffff`,
  all 64 REPORT_DATA bytes must be zero, and a caller-selected session digest
  is rejected. MA binding compares the full digest plus zero padding.
  Captured pre-Version-1 fixtures use an explicit compatibility classification;
  the canonical MA-context verification helper rejects captured-fixture binding.
- MA/tenant envelope request, role and purpose must agree with their nested
  context. The existing MA envelope can carry all legal MA purposes without a
  new record type or size change. Tenant envelopes remain source-only purpose 2;
  contribution records remain inter-node purpose 1 with secret erasure intact;
  authorization results remain migration algorithm `0x0003` only.

These are intentional stricter checks, not a renumbered wire revision.
Previously valid inter-node golden bytes remain unchanged. Previously
encodable illegal combinations, including source-role post-install evidence
or disagreeing header/context fields, now fail closed.
